# حُجَّة

**حُجَّة — الذكاء الاصطناعي للتحقق العلمي والبحث في المراجع الإسلامية الصحيحة**

> باحث ذكي يبحث في المراجع الإسلامية، ويعرض الإجابة مع مصادرها الأصلية للتحقق منها.

بالإنجليزية عند الحاجة: **Hujjah**. النطاق الرسمي: <https://hujjah.maaoun.com>

يبحث في **المكتبة الشاملة** و**تراث**، ثم يصوغ إجابة عربية مستندة حصرًا إلى المقاطع المسترجَعة، ويعرض الأدلة وروابط المصادر الأصلية.

> حُجَّة ليس منصّة لإعطاء «رأي ذكاء اصطناعي»، ولا يُصدر فتوى.
> دوره: **يبحث ← يستخرج ← يقارن ← يلخّص ← يوثّق.**

---

## 1. نتيجة الفحص التقني للمصدرين

قبل كتابة أي كود، فُحص المصدران للتحقق من طريقة وصول **حقيقية ومستقرة ومسموحة**. هذه النتيجة:

### تراث — ✅ متاح ومُتحقَّق منه عمليًا

واجهة JSON عامة على `api.turath.io`، بلا مفتاح وبلا حساب. نقاط النهاية المستخدمة:

| النقطة | الاستخدام |
|---|---|
| `GET /search?q=&ver=3` | بحث نصي في المتون |
| `GET /page?book_id=&pg=&ver=3` | نص صفحة بعينها |
| `GET /book?id=&ver=3` | بيانات الكتاب وتصنيفه |
| `GET /author?id=&ver=3` | ترجمة المؤلف |

استجابة البحث تُرجع لكل نتيجة: `book_name`، `author_name`، `vol`، `page`، `page_id`، `headings[]`، `snip`، `text`.
رابط الموضع الأصلي يُبنى كـ `https://app.turath.io/book/{book_id}/{page_id}`.

**مهم:** لا يستخدم حُجَّة إجابة الذكاء الاصطناعي الجاهزة من تراث. يأخذ منها **نتائج البحث والنصوص فقط**، ونظامنا هو الذي يجمع الأدلة ويقرّر ما يُمرَّر للنموذج.

### المكتبة الشاملة — ⚠️ عبر خدمتها الرسمية فقط

ما تم التحقق منه:

- **لا توجد** واجهة REST عامة موثّقة للبحث في `shamela.ws`.
- `GET https://shamela.ws/search?q=...` يُعيد **نموذج البحث فقط بلا نتائج** — البحث لا يُنفَّذ عبر رابط GET قابل للتوليد.
- الشاملة **تنشر خدمة رسمية عامة للقراءة فقط** عبر بروتوكول MCP على:
  **`https://shamela.ws/mcp`**
  موثّقة في صفحة الدعم الرسمية <https://shamela.ws/page/support>، ونصّها: «خدمة عامة للقراءة فقط، تساعد على البحث في الكتب وفتح صفحات المصدر والتحقق من الاقتباسات. لا تحتاج الخدمة إلى حساب، ولا تعدل محتوى المكتبة.»

لذلك **لا يقوم حُجَّة بأي كشط لموقع الشاملة، ولا يتجاوز أي حماية أو CAPTCHA**. يتصل بالخدمة الرسمية فقط.

#### قيد يجب أن تعرفه

أسماء أدوات خدمة الشاملة ومخططات مخرجاتها **غير منشورة علنًا**، ولم يكن ممكنًا تنفيذ مصافحة حيّة معها أثناء التطوير (بيئة البناء لا تسمح بالاتصال الخارجي). لذلك:

- عميل MCP في `src/lib/search/mcpClient.ts` **لا يثبّت أي اسم أداة مسبقًا**.
- عند أول بحث ينفّذ `initialize` ثم `tools/list`، ويختار أداة البحث في المحتوى من الأدوات التي أعلنها الخادم فعلًا، ويستخرج الحقول بمرونة من الاستجابة.
- إذا تعذّر الاتصال أو لم تُعلَن أداة بحث مناسبة، **يظهر للمستخدم أن المكتبة الشاملة غير متاحة**، ويكمل البحث في تراث وحده. لا تُلفَّق نتيجة واحدة.

للتحقق من حالة الخدمة فعليًا بعد النشر:

```bash
curl -s 'https://<نطاقك>/api/health?probe=1' | jq
```

سيعرض `probe.shamela.tools` بأسماء الأدوات التي تعلنها الخدمة. إن احتاج المُحوِّل تعديلًا طفيفًا بعد معرفة الأسماء، فالموضع الوحيد الذي يُعدَّل هو `pickSearchTool` و`buildUrl` في `src/lib/search/shamela.ts`.

## 2. التشغيل

```bash
npm install
cp .env.example .env.local      # ثم ضع مفتاح Gemini في .env.local
npm run dev                     # http://localhost:3000
```

| المتغيّر | مطلوب | الوصف |
|---|---|---|
| `GEMINI_API_KEY` | ✅ | من <https://aistudio.google.com/apikey> |
| `GEMINI_MODEL` | — | الافتراضي `gemini-2.5-flash` |
| `SHAMELA_MCP_URL` | — | الافتراضي `https://shamela.ws/mcp` |
| `SHAMELA_ENABLED` | — | `false` لتعطيل المصدر |
| `TURATH_API_BASE` | — | الافتراضي `https://api.turath.io` |
| `TURATH_ENABLED` | — | `false` لتعطيل المصدر |
| `RATE_LIMIT_PER_MINUTE` | — | الافتراضي `10` |
| `MAX_QUESTION_CHARS` | — | الافتراضي `500` |

**المفتاح يُقرأ على الخادم فقط.** لا يصل إلى المتصفح، ولا يظهر في أي سجل، وتُنقّى رسائل أخطاء Gemini منه قبل عرضها.

### النشر على Cloudflare والنطاق

هذا المشروع مُعَدّ لـ **Cloudflare Workers عبر OpenNext**، لا لـ Cloudflare Pages/static export؛ لأن المسارين `/api/ask` و`/api/health` يحتاجان تنفيذًا خادميًا ومفتاح Gemini سريًا.

```bash
npm run preview  # يبني التطبيق ويشغّله محليًا على runtime Workers
npm run deploy   # يبني وينشر Worker باسم qaf
```

عند استخدام Cloudflare Workers Builds حيث يكون أمر البناء `npm run build` وأمر النشر `npx wrangler preview`، فإن `npm run build` يقوم الآن بثلاث خطوات: `next build` ثم تحويل OpenNext إلى `.open-next` ثم حقن قيم `previews.vars` المطلوبة في `wrangler.jsonc` من متغيرات البيئة داخل بيئة البناء.

أضف `GEMINI_API_KEY` كـ **Secret** من Cloudflare Workers → `qaf` → Settings → Variables and Secrets، واجعله متاحًا كذلك لبيئة الـ Preview/Build. لا تضع المفتاح داخل `wrangler.jsonc` في Git. لا حاجة إلى قاعدة بيانات أو Supabase في النسخة الحالية.

**النطاق المقصود لهذا المشروع هو النطاق الفرعي فقط:**

```
hujjah.maaoun.com
```

- من Cloudflare Workers → `qaf` → Settings → Domains & Routes، أضف `hujjah.maaoun.com` كـ **Custom Domain**. ينشئ Cloudflare سجل DNS والشهادة تلقائيًا عندما تكون zone `maaoun.com` في الحساب نفسه.
- لا تضف `maaoun.com` أو `www.maaoun.com` كـ Custom Domain أو Worker Route لهذا الـ Worker، ولا تنشئ إعادة توجيه منهما إلى حُجَّة.
- اسم الـ Worker الداخلي هو `qaf`، وقيمة `WORKER_SELF_REFERENCE` في `wrangler.jsonc` هي `qaf` كذلك؛ لا تغيّر أحدهما دون الآخر.
- `metadataBase` و Open Graph و`canonical` مضبوطة على `https://hujjah.maaoun.com`، كما أن عنوان ووصف SEO والكلمات المفتاحية مضبوطة في `src/app/layout.tsx`.
- اترك إدارة `maaoun.com` ومحتواه في إعداد Cloudflare الأصلي، منفصلًا عن خدمة حُجَّة.

### مسار الطلب

```
سؤال
  ↓ التحقق + تحديد المعدّل + رفض محاولات تغيير القواعد
  ↓ [Gemini] تحليل السؤال → 1–3 استعلامات بحث عربية
  ↓ بحث متوازٍ: الشاملة (MCP) ‖ تراث (JSON API)
  ↓ تنظيف + إزالة تكرار + ترتيب + ترجيح المذهب + توزيع عادل بين المصدرين
  ↓ [Gemini] صياغة مستندة إلى المقاطع فقط (JSON مهيكل)
  ↓ التحقق: حذف كل استشهاد بمعرّف غير موجود
إجابة + الدليل + 3–5 مصادر
```

كل مرحلة تُبثّ إلى الواجهة فور وقوعها، فيرى المستخدم حالة كل مصدر لحظيًا.

## 4. ضمانات عدم التلفيق

| الخطر | الإجراء |
|---|---|
| نسبة كلام إلى كتاب لم يُسترجع | النموذج لا يرى إلا المقاطع المسترجَعة؛ وكل استشهاد بمعرّف غير موجود يُحذف برمجيًا بعد التوليد |
| اختراع رقم صفحة أو جزء | الأرقام تُمرَّر من حقول المصدر فقط؛ وعند غيابها يُكتب صراحةً «غير متوفرة» ولا يُطلب من النموذج تقديرها |
| إجابة من المعرفة العامة | عند انعدام الأدلة أو انعدام الاستشهادات الصالحة تُجبر النتيجة على `insufficient` ولا يُعرض نص إجابة |
| فشل مصدر واحد | يستمر الآخر، وتظهر شارة «غير متاح» للمصدر الفاشل مع تنبيه في الإجابة |
| فشل المصدرين | لا إجابة تخمينية: «تعذّر الوصول إلى المصادر حاليًا، لذلك لم أتمكن من التحقق من الإجابة.» |
| روابط ملفّقة | كل رابط يمرّ على قائمة نطاقات بيضاء (`shamela.ws` / `turath.io`) وإلا تُستبعد النتيجة كليًا |
| تصنيف مذهبي من عندنا | انظر القسم التالي |

### فلتر المذهب

الفلتر **ترجيحي لا إقصائي**: يرفع ترتيب المطابق ولا يحذف غيره.

ولا نصنّف أي كتاب أو مؤلف من عندنا. سند التصنيف أحد اثنين فقط، ويُعرض للمستخدم على البطاقة:

1. **تصنيف الكتاب في المصدر** — مطابقة دقيقة لتصنيفات المصدرين الرسمية (`الفقه الحنفي` / `المالكي` / `الشافعي` / `الحنبلي`).
2. **ترجمة المؤلف في المصدر** — ورود وصف المذهب حرفيًا في الترجمة المنشورة في المصدر.

ما لم يتوفّر أحدهما يبقى المذهب **غير معروف**، فلا شارة ولا ترجيح ولا ادّعاء.

## 5. الأمان

- المفتاح في متغيّرات البيئة، على الخادم فقط، ومُنقّى من رسائل الأخطاء.
- تحديد معدّل لكل IP (افتراضي 10/دقيقة) على `/api/ask` و`/api/health`.
- حدود صارمة: طول السؤال، حجم الطلب، عدد الاستعلامات، عدد المقاطع، طول المقطع، مهلة كل مصدر.
- **لا تنفيذ لأي HTML أو JavaScript** قادم من المصادر: كل نص يمرّ على `toPlainText` (إزالة وسوم → فكّ كيانات → إزالة وسوم مجددًا → إزالة محارف التحكم والاتجاه)، والعرض بنص عادي بلا `dangerouslySetInnerHTML`.
- روابط النتائج تحمل `rel="noopener noreferrer nofollow"`.
- رفض الطلبات التي تحاول تغيير قواعد النظام قبل وصولها إلى النموذج، وتحييد أنماط الأوامر داخل نصوص المصادر.
- ترويسات أمان على كل المسارات (`X-Content-Type-Options`، `Referrer-Policy`، `X-Frame-Options`، `Permissions-Policy`).

## 7. وضع التطوير (معزول)

للعمل على الواجهة بلا اتصال بالمصادر:

```bash
HUJJAH_DEV_FIXTURES=true npm run dev
```

- يعمل فقط عندما يكون `NODE_ENV !== 'production'` **و** المتغيّر مضبوطًا — مستحيل تفعيله في الإنتاج.
- يعرض شريطًا أصفر دائمًا في أعلى الصفحة يوضّح أن النتائج من ملف محفوظ.
- البيانات المحفوظة **ليست مخترعة**: نسخة حرفية من استجابة حقيقية لواجهة تراث، بلا تعديل في اسم كتاب أو مؤلف أو جزء أو صفحة أو نص.
- لا يؤثّر على النموذج: الإجابة تتطلّب مفتاح Gemini حقيقيًا في كل الأحوال.

## 8. نطاق النسخة الحالية

- بحث مباشر في المصدرين — **بلا** فهرسة محلية وبلا تحميل كتب إلى قاعدة بيانات.
- بلا حسابات، بلا قاعدة بيانات.
- عند اختلاف المصادر يُعرض الخلاف صراحةً ويُنسب كل قول إلى مقطعه، دون ترجيح.
